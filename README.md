# Eulogy of the Late John Ngugi Gikonyo

React + Vite app: English and Kikuyu eulogy (toggle or side by side) with a photo collage.

    npm install
    npm run dev      # develop
    npm run build    # production build in dist/

- Text lives in `src/content.js` (typed as printed, including original spellings).
- Collage: click a tile or "Add photos" to upload; photos are saved in the browser (localStorage).
- "Print" hides the controls and empty photo slots.
